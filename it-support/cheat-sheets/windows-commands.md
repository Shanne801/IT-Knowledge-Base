# Windows Commands Cheat Sheet

## Network Diagnostics
* `ipconfig /all` - Display full network interface details.
* `ipconfig /flushdns` - Clear the DNS resolver cache.
* `ping [IP/Domain]` - Test network reachability.
* `tracert [IP/Domain]` - Trace route to destination.
* `netstat -ano` - Display active network connections and ports.

## System Maintenance
* `sfc /scannow` - Repair corrupted system files.
* `chkdsk /f` - Check disk for file system errors.
