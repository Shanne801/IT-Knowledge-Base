# IT Knowledge Base & Technical Documentation

Welcome to my personal IT Knowledge Base. This repository serves as a structured collection of technical notes, command cheat sheets, active troubleshooting workflows, and automation scripts developed throughout my journey in IT Support, Infrastructure, and Cybersecurity.

## 🗂️ Repository Structure

* **`it-support/`**: Documentation related to hardware diagnostics, OS administration (Windows/Linux), active directory, and networking fundamentals.
  * `cheat-sheets/`: Quick reference guides for CLI commands and system management.
  * `notes/`: In-depth troubleshooting steps and operational workflows.
  * `scripts/`: System administration and automation scripts (PowerShell, Bash, Python).
* **`cybersecurity/`**: Notes on security frameworks, protocols, network analysis, and hands-on lab writeups (TryHackMe/HackTheBox).
  * `cheat-sheets/`: Command references for networking tools and security utilities.
  * `notes/`: Security concepts, compliance standards, and risk mitigation.
